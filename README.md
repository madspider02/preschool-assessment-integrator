# 幼兒特殊教育評量整合工具

GitHub Pages 部署版（圖片已拆分成 assets 資料夾，避免單一 HTML 過大）。

## 上傳方式

請把以下內容一起上傳到 repository 根目錄：

- `index.html`
- `assets/` 資料夾（內含兩張臺北市發展里程檢核表圖片）

Repository 結構應為：

```
/
├─ index.html
└─ assets/
   ├─ taipei_age4.png
   └─ taipei_age5.png
```

接著到 Settings → Pages → Deploy from a branch，選 `main` 與 `/ (root)`。
